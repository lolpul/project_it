# EngDeck personalized content

Personal English-learning content for EngDeck, focused on technical interviews and remote engineering work.

Current content:
- 165 flashcards / phrases across six decks.
- 11 grammar lessons with 66 exercises.
- Topics: UAV, ArduPilot, INAV, embedded electronics, Linux, Docker, networking, Go, backend, technical interviews and remote-team communication.
- Level target: A2 -> B1, with simple professional English rather than academic vocabulary.

## EngDeck index URL

`https://raw.githubusercontent.com/lolpul/project_it/engdeck-content/engdeck-content/index.json`

Add this URL in EngDeck Settings -> content source, then check for updates.

## Content policy

- Prefer short reusable phrases over isolated vocabulary.
- Keep examples close to real engineering work.
- Every English card should include IPA, a Russian pronunciation hint and a short note when useful.
- Do not replace stable IDs. Increase a deck or lesson version when changing existing content so EngDeck preserves progress.
- Grammar should use technical examples whenever possible.
